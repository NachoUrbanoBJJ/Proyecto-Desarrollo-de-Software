# ISP21: Coding Game

Juego educativo de programación donde el jugador dirige un estudiante a través de un laberinto para llegar a una PC. Construye secuencias de comandos (Avanzar, GirarIzq, GirarDer) y ejecuta tu programa para resolver cada nivel.

## Tecnologías

- React 19 + TypeScript
- Vite 8
- CSS puro

## Instalación

```bash
npm install
npm run dev
```

## Controles

| Comando | Acción |
|---------|--------|
| `Avanzar()` | Avanza un casillero en la dirección actual |
| `GirarIzq()` | Gira 90° a la izquierda |
| `GirarDer()` | Gira 90° a la derecha |

## Comandos Disponibles

```bash
npm run dev      # Servidor de desarrollo
npm run build    # Build de producción
npm run preview  # Vista previa del build
npm run lint     # Verificar código con ESLint
```
